# src/pages/

One file to a page of the app (docs/architecture.md, "The pages").

- `ClipsPage.tsx`: the clip pool, filtered, with each clip's status
- `GuidesPage.tsx`: the style guides, made and edited
- `HomePage.tsx`: the start page: what the app is, new songs, the songs made last
- `JobsPage.tsx`: every prompt sent, as a card, newest first
- `NewPage.tsx`: a prompt for Claude; sending it leads to Jobs
- `SongPage.tsx`: one song, opened
- `SongsPage.tsx`: the songs list
