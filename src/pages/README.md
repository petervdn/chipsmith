# src/pages/

One file to a page of the app (docs/architecture.md, "The pages").

- `ClipsPage.tsx`: the clip pool, filtered, with each clip's status
- `GuidesPage.tsx`: the style guides, made and edited
- `NewPage.tsx`: a prompt for Claude, and the cards of its jobs
- `SongPage.tsx`: one song, opened
- `SongsPage.tsx`: the songs list, the start page
